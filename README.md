# 🎬 ScreenMatch Spring

Projeto desenvolvido durante meus estudos de **Spring Framework** pela [Alura](https://www.alura.com.br/).

Este projeto representa uma evolução do **ScreenMatch**, desenvolvido anteriormente durante meus estudos de Java e Orientação a Objetos. Nesta nova versão, o objetivo é aplicar os conceitos aprendidos no ecossistema Spring e evoluir gradualmente a estrutura da aplicação.

## 🎯 Objetivo

Colocar em prática os conceitos apresentados durante a formação, acompanhando minha evolução no desenvolvimento de aplicações Java utilizando o Spring Framework.

O projeto será desenvolvido progressivamente conforme novos conteúdos forem estudados.

## 📚 Estudos

Este repositório faz parte da minha jornada de aprendizado em **Java e desenvolvimento Back-end**, sendo utilizado para praticar e consolidar os conceitos apresentados nos cursos da Alura.
